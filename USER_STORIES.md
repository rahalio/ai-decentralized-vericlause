# Vericlause — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Smart-contract developer

- As a contract developer, I want CI to run Vericlause on my PR, so that I learn about invariant breaks before review.
- As a contract developer, I want failing traces, so that I can reproduce issues locally.

### Security lead

- As a security lead, I want criticals to block mainnet keys, so that urgency cannot bypass assurance.
- As a security lead, I want waiver expiry, so that temporary exceptions do not become permanent debt.
- As a security lead, I want portfolio heatmaps, so that forgotten contracts do not rot unaudited.

### Release manager

- As a release manager, I want a signed assurance artefact per version, so that go-live has an evidence trail.

### External auditor

- As an external auditor, I want an export pack with specs, tests, and findings, so that my review starts from machine work rather than zero.
- As an external auditor, I want clear waiver history, so that I know what risk management accepted.
